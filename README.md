# Actividad 2: Configuracion de herramientas Git y GitHub

## Objetivo
Practicar el uso de Git y GitHub mediante la creacion de documentos de texto, el registro de modificaciones y la publicacion de cambios.

## Contenido
- Tutoriales: documentos educativos sobre fundamentos de Git, repositorios y control de cambios.
- Informe: carpeta destinada al informe del proceso y sus evidencias.
- README.md: descripcion general del proyecto.

## Proceso realizado
1. Creacion de un repositorio en GitHub.
2. Clonacion del repositorio en el computador.
3. Verificacion de la instalacion y configuracion de Git.
4. Elaboracion de documentos de texto.
5. Preparacion de cambios con git add.
6. Registro de cambios con git commit.
7. Publicacion de cambios mediante git push.

## Comandos utilizados
- git status
- git remote -v
- git add
- git commit
- git push
